# Jeong Yun Mi — Makeup Artist Portfolio

Static portfolio site for makeup artist Jeong Yun Mi ([@jj_yunmi](https://www.instagram.com/jj_yunmi/)),
hosted on Netlify with a Decap CMS admin page at `/admin`.

- `site/` — the website (Netlify publishes this folder)
- `site/admin/` — admin page for adding posts and photos
- `site/content/` — content edited through the admin page
- `scripts/build-data.mjs` — turns `site/content/` into `site/data/posts.js` on each deploy

Setup, deployment and admin instructions (Korean): [DEPLOY.md](DEPLOY.md)
